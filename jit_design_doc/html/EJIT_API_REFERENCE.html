2. 属性宏速查

宏标记对象作用示例关键约束
EJIT_PERIOD_CONST结构体字段时间窗内可读作常量EJIT_PERIOD_CONST uint32_t mode;volatile 跳过；支持整型/布尔/浮点/嵌套结构体/数组
EJIT_IN_PERIOD(static)非数组全局变量运行期不变配置，永远激活EJIT_IN_PERIOD(static) Cfg g_cfg;当前推荐只用 static 标量时间窗
EJIT_IN_PERIOD_ARRAY(name)全局数组/结构体指针按下标独立激活的时间窗数组EJIT_IN_PERIOD_ARRAY(cell) Cfg g_cells[16];固定数组建议 <100；全局最多 1024 个
EJIT_ENTRY函数JIT 特化入口EJIT_ENTRY void f(...)不支持递归；异步模式下副作用应幂等
EJIT_DIM(name)函数参数声明特化维度下标EJIT_DIM(cell) uint8_t idx必须整数；每函数最多 4 个维度
EJIT_PERIOD_GUARD(name)函数修改时间窗数据的生命周期函数EJIT_PERIOD_GUARD(cell) void update(...)必须有同名 EJIT_DIM 参数；可多 period

4. 配置结构体

typedef struct {
  ejit_compile_mode_t compileMode;
  ejit_opt_level_t optLevel;
  size_t maxCodeMemory;
  size_t maxDataMemory;
  size_t maxCacheEntries;
  size_t maxCacheSize;
  bool enableLogger;
  bool forceStaticRegistry;
  const char *dumpJITDir;
} ejit_config_t;
字段说明建议
compileMode同步/异步编译默认先用 SYNC 验证；实时敏感再用 ASYNC
optLevelJIT 优化等级通常 L2；代码体积敏感用 L1
maxCodeMemoryJIT 代码内存上限按目标平台 RAM 设置
maxCacheEntries/maxCacheSizecache 条目/总大小根据维度组合数设置
forceStaticRegistry强制静态注册表路径bare-metal/无构造函数环境开启
dumpJITDir输出优化后 IR排障和确认分支折叠时开启

5. 初始化 / 关闭

ejit_status_t ejit_init(const ejit_config_t *config);
void ejit_shutdown(void);

调用 EJIT_ENTRY 前必须先 ejit_init。传 NULL 使用默认配置。程序退出或不再使用 EJIT 时调用 ejit_shutdown。

6. 生命周期 API

ejit_status_t ejit_activate(const char *periodName, uint8_t cellIdx);
ejit_status_t ejit_deactivate(const char *periodName, uint8_t cellIdx);

ejit_status_t ejit_activate_all(const char *periodName);
ejit_status_t ejit_deactivate_all(const char *periodName);
bool ejit_is_active(const char *periodName, uint8_t cellIdx);

激活状态仅以时间窗/生命周期名称 + 实例 index 为键，没有数组指针维度。数组级接口 ejit_activate_array / ejit_deactivate_array 已移除，因为产品不需要数组级生命周期激活；若多个数组共享同一 period name，激活对该 period 实例整体生效。

接口语义典型使用
activate激活同名 period 下所有数组的某个下标ejit_activate("cell", 3)
deactivate使同名 period 下某个下标失效并触发缓存失效手动修改配置前
activate_all激活某 period 所有实例初始化后批量激活
is_active查询状态调试/断言

8. 内部 wrapper API

void *ejit_compile_or_get(uint64_t cacheKey, void **out_pfn);
普通用户不直接调用该接口。AOT wrapper 会预先计算 cacheKey = funcIdx(32b) | dim[3] | dim[2] | dim[1] | dim[0] 并调用它。返回 NULL 时 wrapper 自动 fallback 到原函数体。

10. 推荐调用序列

ejit_init(&cfg);

// 初始化配置数据
g_cellCfg[idx].mode = MODE_FAST;

// 激活后调用 EJIT_ENTRY
ejit_activate("cell", idx);
process_cell(idx, value);

// 修改配置：推荐生命周期函数
update_cell_cfg(idx, MODE_SAFE, threshold);

// 或手动：deactivate → 修改 → activate
ejit_deactivate("cell", idx);
g_cellCfg[idx].mode = MODE_SAFE;
ejit_activate("cell", idx);

ejit_shutdown();
