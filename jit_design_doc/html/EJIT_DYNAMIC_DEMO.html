2. 场景说明

同步 miss

miss 后业务线程进入冷路径，完成 bitcode 加载、PASS6、LLVM 优化和 JITLink；发布 cache 后本次调用直接执行 JIT。

异步 miss

业务线程只提交任务并 fallback；worker 后台编译和发布，下一次相同 cacheKey 调用才命中特化代码。

Cache hit

展示成熟热路径：wrapper → period active → cache hit → JIT dispatch，不再经过 LLVM 编译。

失败 fallback

展示 runtime 未就绪、inactive、bitcode 缺失、JITLink 失败等情况都安全回退到 AOT 原函数体。
