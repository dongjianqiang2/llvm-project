2. 演示覆盖的关键路径

Cache Hit

wrapper 计算 cacheKey 后直接拿到特化函数指针，调用 JIT 代码，热路径只保留低成本查询。

同步 Miss

当前调用阻塞完成 bitcode 加载、参数替换、PASS6、LLVM 优化和 JITLink；成功后本次执行 JIT。

异步 Miss

当前调用提交后台任务并立即 fallback，worker 编译完成后发布 cache，后续调用命中。

Lifecycle 失效

配置修改前 deactivate，使旧特化代码失效；修改后 activate，下一次 miss 会按新值重新编译。

3. 对照伪代码

void wrapper(cellIdx, args...) {
  cacheKey = make_key(funcIdx, cellIdx);
  if (!ejit_ready() || !ejit_is_active("cell", cellIdx))
    return aot_body(args...);

  if (fn = cache_lookup(cacheKey))
    return fn(args...);

  if (compileMode == EJIT_COMPILE_SYNC) {
    fn = compile_now(cacheKey);
    return fn ? fn(args...) : aot_body(args...);
  }

  enqueue_compile_task(cacheKey);  // dedup by cacheKey
  return aot_body(args...);        // worker publishes cache later
}
