2. 场景说明

生命周期生效：同步 miss

period active 且版本有效，但 Cache Table 中没有当前 cacheKey；业务线程同步完成 bitcode 加载、PASS6、优化和 JITLink，发布 cache 后本次调用直接执行 JIT。

生命周期生效：异步 miss

period active 且版本有效，但 Cache Table miss；当前调用只提交异步任务并 fallback，worker 后台编译并发布到 Cache Table，后续相同 cacheKey 命中。

生命周期生效：cache hit

period active、版本匹配，Cache Table 已有当前 cacheKey 对应的有效函数指针；wrapper 直接跳转到 JIT dispatch，不进入编译流程。

生命周期失效：fallback

period inactive / invalid 或 cache entry 版本过期时，wrapper 不能使用 may_const 特化结果，即使 Cache Table 里存在旧项也必须安全回退到 AOT 原函数体。
