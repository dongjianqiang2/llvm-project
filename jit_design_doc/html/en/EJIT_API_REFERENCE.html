4. Config struct

typedef struct {
  ejit_compile_mode_t compileMode;
  ejit_opt_level_t optLevel;
  size_t maxCodeMemory;
  size_t maxDataMemory;
  size_t maxCacheEntries;
  size_t maxCacheSize;
  bool enableLogger;
  bool forceStaticRegistry;
  const char *dumpJITDir;
} ejit_config_t;
FieldDescriptionRecommendation
compileModeSync/async compilationStart with SYNC to validate; use ASYNC only for latency-sensitive paths
optLevelJIT optimization levelUsually L2; use L1 when code size matters
maxCodeMemoryJIT code memory capSet according to the target platform's RAM
maxCacheEntries/maxCacheSizeCache entry count / total sizeSet based on the number of dimension combinations
forceStaticRegistryForce the static registry pathEnable on bare-metal / no-constructor environments
dumpJITDirOutput the optimized IREnable when troubleshooting or confirming branch folding

5. Initialization / shutdown

ejit_status_t ejit_init(const ejit_config_t *config);
void ejit_shutdown(void);

You must call ejit_init before calling any EJIT_ENTRY function. Pass NULL to use default config. Call ejit_shutdown when the program exits or EJIT is no longer needed.

6. Lifecycle API

ejit_status_t ejit_activate(const char *periodName, uint8_t cellIdx);
ejit_status_t ejit_deactivate(const char *periodName, uint8_t cellIdx);

ejit_status_t ejit_activate_all(const char *periodName);
ejit_status_t ejit_deactivate_all(const char *periodName);
bool ejit_is_active(const char *periodName, uint8_t cellIdx);

Active state is keyed by lifecycle/period name + instance index only; there is no array-pointer dimension. The array-level APIs ejit_activate_array / ejit_deactivate_array were removed because the product does not need array-level lifecycle activation; if multiple arrays share the same period name, activation applies to that period instance as a whole.

APISemanticsTypical use
activateActivates a given index across all arrays of the named periodejit_activate("cell", 3)
deactivateInvalidates an index of the named period and triggers cache invalidationBefore manually modifying config
activate_allActivates all instances of a periodBatch activation after initialization
is_activeQuery stateDebugging / assertions

8. Internal wrapper API

void *ejit_compile_or_get(uint64_t cacheKey, void **out_pfn);
Ordinary users do not call this directly. The AOT wrapper precomputes cacheKey = funcIdx(32b) | dim[3] | dim[2] | dim[1] | dim[0] and calls it. When it returns NULL, the wrapper automatically falls back to the original function body.

10. Recommended call sequence

ejit_init(&cfg);

// initialize config data
g_cellCfg[idx].mode = MODE_FAST;

// activate, then call EJIT_ENTRY
ejit_activate("cell", idx);
process_cell(idx, value);

// modify config: lifecycle function recommended
update_cell_cfg(idx, MODE_SAFE, threshold);

// or manually: deactivate → modify → activate
ejit_deactivate("cell", idx);
g_cellCfg[idx].mode = MODE_SAFE;
ejit_activate("cell", idx);

ejit_shutdown();
